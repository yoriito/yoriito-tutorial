# ref_pal

[The Japanese version of the README is here.](./README-ja.md)

## Overview
This is a reference implementation to run a 3D vehicle widget (generated by Unity WebGL) as an Electron app.

## Directory Layout
```
ref_pal/
  ├── main.js            # Electron entry point
  ├── preload.js         # Script that runs right after the page is loaded
  ├── assets             # Misc. JS files and similar assets
  ├── config/            # Config and maps (VSS → Unity, target definitions, constants, etc.)
  ├── fsm/               # State transitions (FSM) for Door/Trunk/Window/Mirror, etc.
  ├── viss/              # Scripts for VISS (gRPC) connection and Subscribe handling
  ├── window/            # Scripts related to windows (e.g., BrowserWindow creation)
  ├── utils/             # Helper functions (e.g., building Unity messages)
  ├── TemplateData/      # Symlink to ../external/widget-3d-car-unity/TemplateData
  ├── Build/             # Symlink to ../external/widget-3d-car-unity/Build
  └── proto/             # Symlink to ../external/yoriito-viss/proto
```

## Setup / Debug Run

```bash
$ npm install
$ ./init_pal.sh
$ npx electron . --no-sandbox
```

## Build and Distribution

Run the following command to generate a `*.deb` file under the `dist` directory.

```bash
$ npm run dist
$ sudo dpkg -i dist/unity-electron-app_1.0.0_amd64.deb
$ /opt/UnityElectronApp/unity-electron-app
```

## About Vehicle Behavior

In `ref_pal`, a single vehicle feature can be controlled by multiple signals.  
To make the relation between signal combinations and feature behavior clear, this section summarizes the vehicle behavior as state transition tables.

### State Transitions for Signals that Have IsLocked / IsOpen / Position

#### Target Signals

- Vehicle.Body.Trunk.Front
- Vehicle.Body.Trunk.Rear
- Vehicle.Cabin.Door.Row1.DriverSide
- Vehicle.Cabin.Door.Row1.PassengerSide
- Vehicle.Cabin.Door.Row2.DriverSide
- Vehicle.Cabin.Door.Row2.PassengerSide

#### Possible States

- **S0**: (IsLocked=F, IsOpen=F, Position=0) → unlocked & closed
- **S3**: (IsLocked=F, IsOpen=T, Position>0) → unlocked & open
- **S4**: (IsLocked=T, IsOpen=F, Position=0) → locked & closed

#### State Transition Table

| Current              | Target: IsLocked = F | Target: IsLocked = T | Target: IsOpen = F | Target: IsOpen = T        | Target: Position = 0 | Target: Position > 0       |
| -------------------- | -------------------- | -------------------- | ------------------ | ------------------------- | -------------------- | -------------------------- |
| S0 (unlocked/closed) | S0                   | S4                   | S0                 | S3 (Position=100)         | S0                   | S3 (Position=given value)  |
| S3 (unlocked/open)   | S3                   | S3                   | S0 (Position=0)    | S3 (Position=100)         | S0                   | S3 (Position=given value)  |
| S4 (locked/closed)   | S0                   | S4                   | S4                 | S4                        | S4                   | S4                         |

#### Notes

- `Set(IsOpen=true)` is treated as "open fully" (result: Position=100)
- `Set(Position=p)` uses the value `p` as given (partial open is allowed)
- While locked (S4), open requests (IsOpen=true / Position>0) are rejected
- While open (S3), lock requests (IsLocked=true) are rejected (state is kept)

### State Transitions for Signals that Have IsOpen / Position

#### Target Signals

- Vehicle.Cabin.Door.Row1.DriverSide.Window
- Vehicle.Cabin.Door.Row1.PassengerSide.Window
- Vehicle.Cabin.Door.Row2.DriverSide.Window
- Vehicle.Cabin.Door.Row2.PassengerSide.Window

#### Possible States

- **W0**: (IsOpen=F, Position=0) → fully closed
- **W1**: (IsOpen=T, Position>0) → open (partially to fully)

#### State Transition Table

| Current                        | Target: IsOpen = F | Target: IsOpen = T        | Target: Position = 0 | Target: Position > 0       |
| ----------------------------- | ------------------ | ------------------------- | -------------------- | -------------------------- |
| W0 (fully closed)             | W0                 | W1 (Position=100)         | W0                   | W1 (Position=given value)  |
| W1 (open: partially to fully) | W0                 | W1                        | W0                   | W1 (Position=given value)  |

#### Notes

- `Set(IsOpen=true)` is treated as "open fully"
- If you want partial open, use `Set(Position=p)`
- `Set(Position=p)` uses the value `p` as given

### State Transitions for Signals that Have IsLocked / IsFolded

#### Target Signals

- Vehicle.Body.Mirrors.DriverSide
- Vehicle.Body.Mirrors.PassengerSide

#### Possible States

- **M0**: (IsLocked=F, IsFolded=F) → unfolded & unlocked
- **M1**: (IsLocked=F, IsFolded=T) → folded & unlocked
- **M2**: (IsLocked=T, IsFolded=F) → unfolded & locked
- **M3**: (IsLocked=T, IsFolded=T) → folded & locked

#### State Transition Table

| Current                | Target: IsLocked = F | Target: IsLocked = T | Target: IsFolded = F | Target: IsFolded = T |
| ---------------------- | -------------------- | -------------------- | -------------------- | -------------------- |
| M0 (unfolded/unlocked) | M0                   | M2                   | M0                   | M1                   |
| M1 (folded/unlocked)   | M1                   | M3                   | M0                   | M1                   |
| M2 (unfolded/locked)   | M0                   | M2                   | M2                   | M2                   |
| M3 (folded/locked)     | M1                   | M3                   | M3                   | M3                   |

#### Notes

- While locked, Fold/Unfold is not accepted
- Locking does not change the current folded/unfolded state of the mirror
